How this works — no portals

The tool component lives inside the canvas. When mounted, it contributes ordinary Zenith components to the toolbar, inspector, and status bar. Those outlets live elsewhere in the same application tree. When the tool unmounts, its contributions disappear automatically.

const Outlet = compDef({
  draw: vNode => contributions(vNode.attrs.name)
    .map(item => comp(item.component, {
      ...item.attrs, $key: item.id
    }))
});

// A tool's init() registers its UI.
// Its removed() unregisters it.
// Outlets redraw independently.
Experiment: change tools, select a shape, delete it, then add a new one. Watch the contextual UI and lifecycle log.

Lifecycle events

Tool and selection components are the owners of their contributions. Registration and cleanup are automatic; the toolbar itself knows nothing about the tools.
